# Demo Script — 90 Seconds (Outcome Walkthrough)

Goal: lead with the result a client/employer actually cares about — a finished
report in an inbox — then earn the "how" in the seconds that remain. Don't open on
the n8n canvas.

---

**0:00–0:12 — Open on the outcome.**
Show the email inbox: the client report email has just arrived, subject line
visible ("Your 2026-07 Performance Report — Rivertown Fitness Co"). Open it.
> "This landed on its own, at 8am on the first of the month. No one wrote it."

**0:12–0:35 — Open the attached PDF, scroll through it.**
Show the branded header, the executive summary paragraph, the sentiment badge, the
notable-changes list, the metrics table with trend bars.
> "The summary is AI-generated, but grounded — it's only allowed to talk about the
> numbers it was given. When something crosses the threshold, it's flagged here in
> the table. When nothing does, it says so, instead of forcing a change out of
> nothing."

**0:35–0:50 — Cut to Drive.**
Show the dated "Reports - 2026-07" folder containing the same PDF.
> "It's filed automatically too — same run, same file, no separate step."

**0:50–1:10 — Cut to the n8n canvas, briefly.**
Show the full pipeline zoomed out for 3–4 seconds, then zoom into the Config node.
> "One pipeline, one config node per client — sheet, thresholds, recipient emails,
> even which PDF engine to use. Onboarding a new client is editing this node, not
> rebuilding the workflow."

**1:10–1:25 — Show the run log (Data Table).**
Scroll the CRG_RunLog table showing several rows: `success`, `skipped`, with
durations.
> "Every run is logged. Run it twice for the same month by accident and it skips
> cleanly — no duplicate email, no duplicate file."

**1:25–1:30 — Close.**
> "Built to run unattended — which is the point. More on the failure handling in
> the next clip."

---

**Shot list:** inbox → opened email → PDF (scrolled) → Drive folder → n8n canvas
(wide, then Config node) → Data Table rows. Six shots, no dead air between them.
